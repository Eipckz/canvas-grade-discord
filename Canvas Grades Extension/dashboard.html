How sending works

Grades are sent to Discord each time you open Canvas (at most once every minutes, so clicking around Canvas doesn't spam the channel). If Canvas isn't opened all week, a backup check runs Friday–Sunday at 6 PM Eastern while the browser is open. Letter grade changes are posted as a separate summary message. GPA is an estimate (A–F = 4–0, score fallback 90/80/70/60).
